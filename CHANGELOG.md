# Changelog

## 0.1.0 - 2026-09-23

Initial MVP release.

### Added

- Local resume and JD matching workflow
- Batch ranking for `.md` / `.txt` job descriptions
- CSV job import
- JSONL job import for crawler/export pipelines
- HTML snapshot job import
- Evidence-based fit scoring
- Skill gap analysis
- Interview question generation
- Fact-grounded resume tailoring report
- Browser-friendly HTML report
- Configurable scoring weights and keyword taxonomy
- Optional OpenAI-compatible LLM parsing with JSON repair and rule fallback
- Unit tests and GitHub Actions workflow
