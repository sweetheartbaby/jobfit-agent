## 项目：企业知识库 RAG 问答系统

基于 LangChain 构建企业知识库问答系统，负责文档切分、向量检索、Reranker 重排和答案引用展示。使用 Milvus 存储向量，结合关键词检索提升召回效果。针对检索不到证据的情况设计低置信拒答和人工复核机制。

## 项目：多 Agent 舆情分析 Demo

使用 LangGraph 设计 Supervisor、Collect、Analyze、Report 多 Agent 工作流，实现任务路由、工具调用、失败重试和报告生成。通过 WebSocket 返回任务状态。
